# Character Design Card Template

## Full Prompt (Adapt Character Details)

```
生成一张3:4竖版武侠角色设计卡，杂志式档案排版，纯白背景。

一、人物：[角色名]，[年龄]岁。[五官细节——必须含东方脸锚：
纯正东方面孔，眉骨平缓眼窝浅，狭长丹凤眼内双，黑色瞳仁，
鹅蛋脸下颌线柔和，鼻梁挺直鼻翼窄小，薄唇]。

二、固定服装：[服装描述，含材质对撞元素]。
所有视角与表情图必须同脸同发型同服装，细节一致。

三、版式：
- 顶部10%：英文标题"[ENGLISH NAME]" + 中文名 + 编号"No.XX"
- 主体50%三栏：
  左=人物资料+胸像特写
  中=正面/侧面/背面三视图（同高同基线，自然站姿）
  右=2列×3行表情参考（冷静/冷笑/隐怒/悲怆/决然/空洞）
- 下方28%三栏：
  服装拆解（实物图）/ 道具 / 四个色块（主色系）
- 底部12%：一句话简介 + 关键词

四、要求：细线分栏无粗框，人物比例自然手指正常，
无水印无乱码，剧组设定页质感。
```

## Eastern Face Anchor (MUST Include)

```
纯正东方面孔，眉骨平缓眼窝浅，狭长丹凤眼为内双眼皮，
黑色瞳仁，鹅蛋脸下颌线柔和，鼻梁挺直鼻翼窄小，薄唇
```

Without this explicit anchor, AI models will drift toward Western deep-set facial features.
