# Emotion Vocabulary (80 → Essential 20)

> Core principle: Emotion = specific facial muscle behavior, NOT adjectives.
> Use these in reaction shots and character close-ups.

## 杀意/冷冽 (Killing Intent / Cold)
| Emotion | Physical Description |
|---|---|
| 冷眼相视 | 眼神冰冷，嘴角微抿，下巴微抬，面无表情但压迫感强 |
| 隐忍蓄力 | 嘴唇紧抿，眼皮微垂，拳头微微攥紧，呼吸放缓 |
| 爆发前兆 | 额头青筋微凸，嘴唇颤抖，眼神像要喷火 |
| 得意冷笑 | 单边嘴角用力上挑，眼睛半眯，眉毛微微上扬 |

## 悲怆/克制 (Grief / Restraint)
| Emotion | Physical Description |
|---|---|
| 眼眶泛红 | 眼周泛红，泪水在眼眶打转，眼神失焦，嘴唇微颤 |
| 苦笑 | 嘴角勉强上扬，但眼睛没有笑意，眉头微蹙 |
| 空洞麻木 | 瞳孔放大失焦，表情僵硬，嘴角平直，像被抽空了灵魂 |

## 温柔/暖意 (Tenderness / Warmth)
| Emotion | Physical Description |
|---|---|
| 宠溺笑 | 嘴角温柔上扬，眼角细纹微微出现，眼神柔软 |
| 羞涩低头 | 嘴角抿着微笑，眼神躲闪，脸颊泛红，头微微低垂 |
| 天真无邪 | 眼睛睁大明亮，嘴角自然上扬，脸颊饱满，表情纯净 |

## 震惊/转折 (Shock / Turning Point)
| Emotion | Physical Description |
|---|---|
| 瞳孔收缩 | 瞳孔骤然收缩，眼睛瞪大，身体本能后倾 |
| 笑意破碎 | 脸上的笑意骤然停滞、瞬间破碎，眼眶迅速泛红 |
| 拳心收紧 | 掌心旧伤隐约渗出血丝，手指缓慢用力攥拳，青筋微浮 |
