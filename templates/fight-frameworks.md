# Fight Framework Skeletons (4 Types)

## Type 1: One vs Many
```
骨架:
1. 全景交代主角与每名对手的位置
2. 对手按不同方向和节奏发起(差异化进攻)
3. 主角用一个对手的位移阻挡另一个对手
4. 画面保留已退出战斗的人与物
5. 结尾明确剩余人数和主角去向

规则:
- 每回合只有一个对手出手
- 其余对手停在可见等待位
- 主角转身换向=换轴线→先全景重新交代
- 倒地者在后续镜头必须保持可见
```

## Type 2: Duel (1v1)
```
骨架:
1. 建立威胁与实力对等
2. 第一回合:试探性交手
3. 升级:武器锁定/近身缠斗
4. 决定性一击(全片唯一慢动作)

量化(15s中间型):
- 交锋 6-8次
- 微动作 12-16个
- 镜头 5-7个
- 特写 0.8-1.5s
```

## Type 3: Ranged Energy
```
骨架:
1. 蓄力(武器发光/空气扭曲/碎石悬浮)
2. 弹幕交换(剑气/能量波/光束)
3. 格挡/偏转(盾牌/剑幕/屏障)
4. 终极技(全屏VFX/色彩反转/天地异象)

VFX密度要求:
- 蓄力:武器裂纹发光+空气涟漪
- 发射:能量轨迹如彗星尾
- 命中:十字冲击波+同心圆扩散
- 终极:山峰断裂能量波+粒子弥漫
```

## Type 4: Solo Breakthrough
```
骨架:
1. 建立路线和出口
2. 第一种威胁迫使改变路径
3. 第二种威胁封住原路
4. 最后障碍检验已建立的能力
5. 抵达/脱离/停在清晰位置
```
