> **用测试工程师的思维，做电影级的 AI 武侠短片。**

## 为什么做这个项目？

AI 视频工具（Seedance、可灵、即梦、Vidu 等）让"生成一段视频"变得极其简单。但要做一条 **15-30 秒的电影级武侠短片**——角色全程一致、打斗有真实动作逻辑、镜头语言专业、节奏有呼吸感——依然很难。

市面上大多数教程只教你"怎么写一条提示词"。这个项目教的是：

- **像导演一样思考**（镜头语言、叙事节奏、视觉签名）
- **像武术指导一样编排**（交手账、拆段纪律、卖打击四件套）
- **像测试工程师一样品控**（四门质检、静默自检、拉片回归）

## 与其他方案的区别

| 现有方法 | 本项目 |
|---------|--------|
| "写一条漂亮的提示词" | **七步生产流程 + 四门质检门禁** |
| 一次性生成整段 | **拆段纪律**（一段=一个动作，模型不压缩不删减） |
| 抽卡碰运气 | **12 条铁律**（每条经 A/B 测试或逐帧验证） |
| 手动反复试错 | **CLI 自动化 + 预算熔断机制** |
| 泛用"电影感" | **武侠/仙侠专项**：打斗骨架库、能量美学、东方面孔锚定 |

## 核心发现（全项目最重要的一条）

经过分析爆款 AI 打斗视频（播放量 390 万+）、自制 6 条短片、运行 A/B 对比测试后，最大的发现是：

> **AI 视频模型不会删掉多余动作——它会把它们压缩到看不清。**
>
> 解法不是更好的提示词，而是**把一场复杂打斗拆成简单的单动作段**，后期剪辑组装。

这个发现催生了"拆段编排法"，稳定输出 9+/10 分：

```
❌ 传统写法："双方极速近身连续三次剑刃碰撞"
   → 模型渲染成两个人站着摆姿势

✅ 拆段写法：3 段 × 每段 1 个动作
   段 A：横斩 + 格挡     → 模型渲染真实物理
   段 B：反击 + 侧身卸力  → 模型渲染重心变化
   段 C：终极碰撞 + 冲击波 → 模型渲染全力一击
   → 后期 1.35 倍速剪辑拼接 → 密集且真实的打斗
```

## 七步生产流程

```
① 定规格    → 时长（抖音主力 15 秒）、画幅（9:16）、强度档、速度档
② 选骨架    → 按场景类型匹配打斗骨架（references/02）
③ 写交手账  → 每回合三格（发起/应对/结果），每回合必改一项结果
④ 反解成稿  → 用反解格式写完整提示词（references/04）
⑤ 贴光效    → 选一套光效预设贴入（templates/lighting-presets.md）
⑥ 过四门    → 技术检 + 静默自检 + 审美检 + 合规检
⑦ 交付      → 生成 → 下载 → 1.35x 剪辑 → 发布
```

## 12 条铁律速览

| # | 铁律 | 一句话 |
|---|------|--------|
| 1 | 拆段或败 | 一段生成=一个动作过程，禁止多拍编舞 |
| 2 | 两事件上限 | 每镜最多 2 个事件；慢动作全片最多 1 处 |
| 3 | 状态链+次级反应 | 起点→动作→终点 + 披风飘/烟尘落/余烬灭 |
| 4 | 首帧占用锁 | 第一可见帧必须包含全部角色且位置正确 |
| 5 | 空间可测量 | "1 米内"代替"旁边"，"前景三人清晰"代替"很多人" |
| 6 | 物理锁 | 重心转移/布料延迟/武器重量；禁漂浮瞬移 |
| 7 | 运镜六项 | 场景/起始/调度/运动/焦点/终点，一镜一运镜 |
| 8 | 情绪=镜头行为 | "瞳孔收缩映刀光"代替"他很愤怒" |
| 9 | 东方面孔锚 | 必须显式写"中国人长相"，否则模型漂向西式脸 |
| 10 | 材质对撞 | 丝绸×金属浮雕=惊艳感来源；一主色+一点缀色 |
| 11 | 卖打击四件套 | 环境冲击波优先 / 遮接触点 / 反应方向一致 / 声音余波 |
| 12 | 声音时间线 | 开场即有声 / 蓄力骤停 / 决胜爆发 / 收半拍 |

## 四门质检

| 门 | 检什么 | 谁说了算 |
|----|--------|---------|
| 门 1 · 技术检 | 手指/兵器/面部/穿模/倒地者消失 | 客观，VLM 自动检 |
| 门 2 · 静默自检 | CINEDANCE 20 项（@标签/道具在手/物理可能/时间块一致） | 出稿前静默过，不过不发 |
| 门 3 · 审美检 | 东方脸锚/材质对撞/光晕/散景 | 用户一票否决 |
| 门 4 · 合规检 | 暴力弱化/无血腥词/无版权名/AI 标识 | 平台规则 |

## 反解格式（提示词母语）

```markdown
【人物固有资产】 ← 每段原样重复，一字不改
【固定锚点】     ← 每段原样重复
【光线布置】     ← 从预设库选一套贴入

0-1.5秒：钩子（大特写，第一帧即有声音）
1.5-4秒：蓄势（后拉大全景，压迫感建立）
4-9秒：  爆发（分段动作+能量轨迹+环境破坏）
9-12秒： 决胜（全片唯一慢动作 + 色彩反转 + 特效最大化）
12-15秒：定格（英雄剪影 + 粒子飘落 + 声音收半拍）

【交接状态】 ← 本段末帧 = 下一段起始
【声音时间线】← 逐秒声音事件

负面约束：无文字水印/比例正常/无多余动作
```

## 特效密度层

特效不是点缀——是主菜。每个动作节点都需要特效指令：

| 时刻 | 必须有 | 提示词关键词 |
|------|--------|-------------|
| 蓄力 | 武器发光/空气扭曲/碎石悬浮 | "剑身裂纹发亮如岩浆" "空气涟漪" |
| 移动 | 能量轨迹/速度线/环境扰动 | "残影划出能量轨迹如彗星尾迹" |
| 碰撞 | 冲击波/粒子爆发/地面裂缝 | "十字冲击波同心圆扩散" "冰原裂开" |
| 子弹时间 | 悬浮粒子/碎片反光/发丝静止 | "数万冰晶悬浮每块映出倒影" |
| 余波 | 连锁反应/能量残留 | "雪山一座接一座崩塌" |
