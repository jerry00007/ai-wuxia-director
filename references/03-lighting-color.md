# Lighting & Color for AI Video

## 8 Lighting Presets (Copy-Paste Ready)

### 1. Window Soft Light (Indoor, Intimate)
```
【光线布置】以窗边自然柔光作为主光，光源从人物侧前方斜向进入，柔和照亮半边脸、眉眼、鼻梁、嘴唇、手部和衣领。另一侧脸缓慢进入自然阴影，保留皮肤纹理和五官结构。正面只有极弱漫反射补光，眼睛中保留温润眼神光。背景轻微虚化，窗外高光不过曝。
```

### 2. Overhead Skylight (Daytime, Natural)
```
【光线布置】以顶部或斜上方自然天光作为主光，柔和覆盖头顶、肩膀、发丝和上半身。脸部曝光自然，眼窝、鼻梁下方和下巴保留轻微阴影。正面加入少量地面反射光，避免眼睛过暗。背景明亮且保留层次。
```

### 3. Overcast Diffusion (Realistic, Low Contrast)
```
【光线布置】厚云层形成大面积冷灰色漫射环境光，没有清晰硬阴影。人物、服装和背景被柔和覆盖，整体光比较低，五官与衣料纹理仍然清楚。人物正面不加强补光，只保留自然眼神光。背景饱和度略低。
```

### 4. Golden Hour Backlight (Emotional Peak)
```
【光线布置】低角度暖金色阳光从人物侧后方照来，打亮发丝、肩膀、侧脸轮廓和衣服边缘。正面使用同方向环境反射形成柔和暖色补光，保留面部结构。空气中只有轻微雾感，边缘光明亮但不过曝，背景呈暖色散景。
```

### 5. Dawn Mist (Quiet Opening)
```
【光线布置】清晨低角度柔光从侧后方穿过薄雾，轻轻照亮发丝、肩部、脸部侧缘和衣料纹理。正面以极弱环境反射保留面部层次。雾气在光路中形成柔和体积光，远景逐渐淡化。
```

### 6. Moonlight Cold (Wuxia Night, Solitude) ⭐ Most Used
```
【光线布置】蓝白色月光从人物侧上方或侧后方照来，打亮一侧脸、发丝、肩膀和衣服边缘。正面只保留极弱冷灰色环境补光，暗区仍有眼眶和下颌结构。背景整体压暗，远处仅有微弱环境亮度。月光方向与阴影方向保持一致。
```

### 7. Candlelight Warm (Intimate Interior)
```
【光线布置】人物侧前方近距离烛火发出暖黄色柔光，照亮靠近烛火的一侧面颊、下巴、嘴唇、鼻梁下缘、手指和衣服前襟。光照范围有限，离开烛火后快速衰减。亮度只有轻微自然跳动，背景较暗并有少量虚化烛火。
```

### 8. Lantern Ambience (Festival, Night Market)
```
【光线布置】沿街高悬的红灯笼发出暖红色环境光，柔和照亮人物面部和衣缘，地面反射少量暖色光斑。远处灯笼逐渐虚化为光点，近处灯笼轮廓清晰。人物面部保持自然肤色的同时衣缘染上暖红色调。
```

**Usage Rules**: One preset per film. Replace subject positions and light sources before pasting. Never stack multiple presets.

## Color Discipline

**Iron Rule**: One dominant color + one accent color. Never five colors.

| Color | Emotion | Wuxia Application |
|---|---|---|
| Cyan/Blue | Cold, fate, night | Snow, ice, moonlight, assassins |
| Rust Orange | Fire, warmth, danger | Torches, embers, blood (implied) |
| White | Purity, death, truth | Snow, mourning, blank scrolls |
| Gold | Glory, power | Imperial, divine, sword energy |
| Black | Authority, unknown | Night, heavy armor, void |

### Color Reversal (The "Awakening" Technique)
The dominant color flips to the accent color at the climax moment:
- Before: cold cyan-blue dominance
- THE STRIKE: explosion of rust-orange
- After: return to cold cyan-blue
This is the visual equivalent of a musical key change.
